# 应用工况与适用范围

`markov-entropy` 目前最适合用于**有限状态随机系统的信息量分析、随机信道组合验证，以及连续分布信息量算法的实验性原型**。

## 1. 通信信道与编码分析

适合分析有限输入、有限输出的离散信道，例如：

- 二元对称信道 BSC
- 二元擦除信道 BEC
- 多级离散信道
- 串联或并联信道
- 编码、传输、解码组成的处理链

可以计算或验证：

- Shannon 熵与 Rényi 熵
- KL 散度、总变差距离
- 互信息与条件互信息
- 数据处理不等式
- 信道复合后的信息损失
- 独立信道的张量可加性

**典型问题：**噪声增加后保留了多少输入信息？两个处理阶段中哪个造成的信息损失更大？

## 2. 传感器与检测系统

可以把真实状态、传感器读数和分类结果建模为随机信道，适用于：

- 故障诊断传感器
- 雷达或视觉检测结果
- 告警系统的误报、漏报分析
- 多阶段检测与识别流程
- 离散传感器融合

**典型问题：**

- 传感器输出对真实状态包含多少信息？
- 增加一个后处理步骤是否会降低辨识能力？
- 两个传感器分别或联合使用时的信息增益是多少？

## 3. 工业设备状态与可靠性分析

设备状态可以表示为有限状态空间，例如：

```text
正常 → 轻微退化 → 严重退化 → 故障
```

适合研究：

- 离散状态转移
- 故障模式识别
- 检修前后的状态分布差异
- 不同工况下设备状态分布的 KL 或 Rényi 散度
- 监测链路中的信息衰减

它可以作为可靠性分析的**信息论补充工具**，但目前不是完整的可靠性、寿命预测或维修优化平台。

## 4. 生产与业务流程中的随机管线

FinStoch 的信道复合能力适合表示多阶段随机流程，例如：

```text
原料等级 → 加工结果 → 质检结果 → 最终分级
```

或者：

```text
用户特征 → 推荐结果 → 点击行为 → 转化结果
```

可以用于：

- 比较不同流程方案
- 定位信息损失最大的环节
- 分析中间变量与最终结果之间的依赖
- 验证删除或合并某个处理阶段的影响
- 研究独立子系统组合后的整体信息量

## 5. 机器学习分类器与概率模型评估

适合中小规模、类别有限的模型输出分析，例如：

- 混淆矩阵对应的随机信道
- 分类器概率输出
- 标签噪声模型
- 模型压缩或后处理
- 数据分布漂移
- 不同模型预测分布比较

可以回答：

- 预测结果包含多少标签信息？
- 后处理是否损失信息？
- 训练集与生产环境的输出分布差异有多大？
- 两个分类器的概率行为是否明显不同？

项目目前**不是模型训练框架**，更适合作为评估、验证和研究组件。

## 6. 隐私机制与数据脱敏分析

随机响应、离散扰动、聚合和脱敏过程都可以表示为随机信道。

适合进行：

- 原始数据与脱敏数据的信息依赖分析
- 隐私处理前后的互信息比较
- 多阶段脱敏流程的信息损失分析
- 随机响应机制的实验验证

当前项目还没有实现完整的差分隐私机制、隐私预算组合或正式隐私证明，因此适合**原型分析**，不应直接作为生产级隐私合规工具。

## 7. 生物信息与离散序列模型

对于有限字母表或有限类别数据，可以用于：

- DNA 碱基替换信道
- 离散表型或基因型分布
- 序列分类结果
- 群体分布差异
- 多阶段生物检测流程

尤其适合分析有限分类变量之间的熵、散度和条件依赖关系。

## 8. 概率论、信息论与范畴论教学

这是项目当前非常突出的用途：

- 演示 FinStoch 范畴
- 展示 `copy`、`discard`、`composition`、`tensor`
- 用 DisCoPy 绘制随机信道弦图
- 数值验证论文定理
- 比较 Shannon、Rényi、Gini–Simpson 信息量
- 验证链式法则、数据处理不等式和张量可加性
- 通过 Notebook 进行可复现实验

项目适合用于课程示例、论文配套代码和研究结果复现。

## 实验性 `stoch` 后端可用工况

对于连续分布或较大样本空间，`markov_entropy.stoch` 目前可以用于实验性研究：

- 给定密度函数和积分器的 KL、Rényi、TV 计算
- 有限划分下的信息量下界
- 比较划分逐步细化后的收敛趋势
- Monte Carlo 期望与 KL 估计
- 输出标准误和置信区间
- 验证离散近似与连续计算是否一致

适合：

- 一维或低维连续分布
- 已知概率密度的模型
- 用户能够提供可靠积分器的场景
- 独立同分布采样的 Monte Carlo 实验

这部分目前标记为**实验性功能**，更适合研究和算法验证，而不是直接投入关键生产系统。

## 当前最匹配的项目定位

综合来看，项目当前最有价值的三个方向是：

1. **信息论与 Markov 范畴研究的可执行参考实现**
2. **有限状态随机系统和多阶段随机管线的分析工具**
3. **通信、传感、分类和隐私机制的信息量原型验证库**

## 暂时不建议直接用于

- 超大规模状态空间或高维稀疏矩阵
- GPU 或分布式计算
- 实时工业控制
- 完整的 MDP/POMDP 求解
- 通用 Markov Chain Monte Carlo
- 任意可测空间与通用 Markov kernel
- 高维密度估计
- 相关样本、时间序列的严格误差分析
- 安全关键系统的最终认证计算

这些场景需要继续增加稀疏计算、可测核、专用积分器、相关样本误差以及性能基准等能力。
